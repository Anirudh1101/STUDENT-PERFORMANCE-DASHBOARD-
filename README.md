# 📊 Student Performance Dashboard

An interactive Excel dashboard that analyses the academic performance of 100 Class 10 students across four sections (10A–10D). Change a filter and every number, chart and table updates instantly, with no macros or VBA, only Excel formulas.

## ✨ Features
- **Dynamic filters:** drop-downs for Class (All, 10A–10D) and Gender (All, Male, Female)
- **KPI cards:** Total Students, Average %, Pass Rate, Average Attendance and Top Scorer
- **6 charts:** Average Marks by Subject, Grade Distribution, Class-wise Average %, Pass vs Fail, Attendance vs Performance, and Student vs Class Average vs Topper
- **Top 10 leaderboard:** ranks students based on the selected filters, with gold, silver and bronze highlights
- **Individual report card:** pick any student to see their marks, ranks and comparison with the class average and topper
- **Auto-generated insights:** text summaries that rewrite themselves for every filter

## 🗂️ Workbook Structure
| Sheet | Purpose |
|---|---|
| Dashboard | Filters, KPI cards, charts and Top 10 table |
| Student Report | Individual report card with a student selector |
| Data | Sample dataset: marks in 5 subjects, attendance and study hours |
| Calc | Formula-driven chart data linked to the filters |
| Guide | Explains how each part of the dashboard works |

## 🛠️ Excel Concepts Used
Data Validation · IF / AND / OR · SUM · AVERAGEIFS · COUNTIFS · INDEX + MATCH · LARGE · MAXIFS · TEXT · Conditional Formatting · Charts

**Grading:** A+ ≥ 90, A ≥ 80, B ≥ 70, C ≥ 60, D ≥ 40, else F. A student passes only if they score at least 33 in every subject.

## 🚀 How to Use
1. Download `Student_Performance_Dashboard.xlsx`.
2. Open it in **Microsoft Excel** or **Excel Online**. If you see "Enable Editing", click it.
3. Pick a Class and Gender from the yellow drop-downs on the Dashboard.
4. Try editing any marks on the Data sheet and watch everything update.

> GitHub can't preview `.xlsx` files, so download the file to explore it.
